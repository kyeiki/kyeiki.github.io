Unduh Berkas ​

Seluruh berkas praktikum dapat diunduh langsung dari halaman ini - tidak perlu akses repositori. Simpan berkas ke folder kerja Anda, lalu buka di Blender 4.3 melalui tab Scripting -> Text -> Open dan jalankan dengan Run Script (Alt + P).

Alur Penggunaan Singkat ​

  1. Unduh modul3.py (atau modul2.py) dari tabel Kode Sumber di atas.
  2. Unduh Jobsheet sesuai modul, cetak, dan isi sambil praktikum.
  3. Buka Blender 4.3 -> tab Scripting -> Open -> pilih berkas .py -> Alt + P.
  4. Simpan pekerjaan sebagai prak[N]_[NIM].blend sesuai ketentuan pengumpulan di modul.
