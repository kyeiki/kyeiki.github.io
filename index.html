Pipeline ASCII → JSON → 3D

Gambar denah dengan karakter +, -, | dan nama ruangan, lalu jalankan Run Script (Alt + P) di Blender 4.3.

📦

Furnitur Primitif Otomatis (OCP)

Library AssetBuilder membangun meja, kursi, sofa, tempat tidur, dan lainnya dari bentuk primitif berbasis kata kunci ruangan.

🎨

Material Palet PBR

Palet RGBA terpusat di config_assets.json dengan Principled BSDF khas Blender 4.3 — tanpa hardcode warna.

🧩

Arsitektur SOLID

AsciiDenahParser, WallBuilder, DoorWindowBuilder, hingga SceneManager — tiap kelas satu tanggung jawab (SRP), mudah dikembangkan (OCP).
