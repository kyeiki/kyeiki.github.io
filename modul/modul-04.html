BAGIAN I. BAHAN KAJIAN ​

I.1. Penggunaan Pedoman ​

Titik awal praktikum adalah skrip modul4_kamera_animasi_citytour.py. Saat dijalankan di Blender 4.3 (Run Script / Alt + P), skrip membangun ulang kawasan makro 3 gedung - kini dengan koleksi tambahan CameraRig_Modul4 berisi 4 kamera virtual + kurva spline drone - mengatur timeline frame 1-240 @ 24 fps, mem-bake seluruh animasi, lalu mendaftarkan panel CityTour M4 di N-Panel. Viewport otomatis masuk mode Rendered dari pandangan kamera aktif.

Dokumen pendamping (unduhan):Suplemen Dosen - Panduan Detail Pengerjaan Task I-V (.docx) - penjelasan langkah demi langkah tiap task untuk dosen/instruktur. Jobsheet Mahasiswa Modul 4 (.docx) - lembar kerja siap cetak yang diisi mahasiswa saat praktikum.

Gambar 1. Hasil bidikan Cam_Drone_Orbit pada frame 120: kamera drone mengorbit kawasan saat matahari senja - "film" 10 detik inilah yang akan diproduksi di modul ini.

I.2. Konsep Dasar 1 - Frame, FPS, dan Timeline (untuk pemula) ​

Video adalah deretan gambar diam yang diputar cepat. Satu gambar disebut frame. FPS (frames per second) = banyaknya frame yang diputar per detik - modul ini memakai 24 fps (standar film sinema). Timeline 1-240 frame berarti durasi 240 / 24 = 10 detik. Panel Timeline di bagian bawah viewport adalah "mesin waktu" Blender: geser playhead (garis biru) untuk melompat ke frame tertentu, tekan Spacebar untuk play/pause.

I.3. Konsep Dasar 2 - Keyframe dan Interpolasi (BEZIER vs LINEAR) ​

Keyframe = "potret" nilai sebuah properti pada satu frame tertentu - posisi, rotasi, energi lampu, warna, apa saja. Contoh: "mobil di x=2 pada frame 1" dan "mobil di x=64 pada frame 240". Blender lalu menginterpolasi (menghitung nilai-nilai di antara dua keyframe) sehingga mobil melaju mulus tanpa kita menggambar 240 frame satu per satu - inilah inti animasi 3D.

Modul ini memakai dua mode interpolasi:

ModeBentuk gerakanDipakai untuk
BEZIERpelan -> cepat -> pelan (halus, ada percepatan)lift kaca (berangkat & mendarat lembut)
LINEARkecepatan tetap konstanmobil & putaran roda, kipas HVAC

Nilai animasi tersimpan sebagai kurva F-Curve (grafik nilai vs frame) yang bisa dilihat di editor Graph Editor.

I.4. Konsep Dasar 3 - Kamera Virtual: Proyeksi, Lensa, DOF ​

Blender menampilkan dunia lewat kamera virtual. Tiga hal paling menentukan tampilannya:

  1. Proyeksi - PERSP (perspektif) meniru mata manusia: objek jauh mengecil dan garis sejajar bertemu di titik hilang (vanishing point). ORTHO (ortografis) memakai sinar sejajar: ukuran objek tidak berubah walau jauh - cocok untuk blueprint, peta, dan game strategi.
  2. Focal length (panjang fokus lensa, mm) - kecil (24 mm) = sudut pandang lebar (wide, banyak konteks); besar (85 mm) = tele (objek terlihat dekat/zoom).
  3. DOF (Depth of Field) - area tajam di depan-belakang titik fokus. Aperture f-stop kecil (f/2.0) = area tajam tipis sehingga latar menjadi bokeh (buram lembut) - ciri khas film malam.

I.5. Konsep Dasar 4 - Spline Path & Constraint ​

Jalur drone adalah kurva Bezier 3D tertutup (8 titik, use_cyclic_u) berbentuk elips dengan gelombang naik-turun ketinggian. Perhatikan: kamera drone tidak punya satu pun keyframe lokasi! Gerakannya murni hasil dua constraint:

  • FOLLOW_PATH - memaksa kamera berjalan menyusuri kurva; animasinya datang dari properti kurva eval_time yang di-keyframe 0 -> 240.
  • TRACK_TO - memutar kepala kamera agar sumbu -Z selalu mengarah ke Target_PlasaFocus di atas plasa.

I.6. Konsep Dasar 5 - Render Video MP4 & Ekspor Web 3D GLB ​

Render MP4: Blender merender 240 frame satu per satu lalu encoder FFmpeg menjahitnya menjadi video H.264 (.mp4) - codec standar yang diputar YouTube/WhatsApp/HP siapa pun. Tersedia 720p (uji cepat) dan 1080p (final). Ekspor GLB (glTF 2.0): seluruh scene (mesh + hierarki + animasi + kamera + lampu) dibungkus menjadi SATU file biner .glb yang bisa dibuka di viewer web (three.js, model-viewer) - "JPEG-nya dunia 3D".

LAMPIRAN A. GLOSSARIUM ​

IstilahArti

InterpolasiPerhitungan nilai antar keyframe; BEZIER = pelan-cepat-pelan, LINEAR = konstan

Spline / Kurva BezierJalur mulus melalui titik kontrol; cyclic = ujung menyatu membentuk loop
ConstraintPengikat transformasi; FOLLOW_PATH menempel objek ke kurva, TRACK_TO menghadapkan objek ke target
Eval timeProperti kurva (0..path_duration) yang menentukan posisi sepanjang jalur
BakeMenuliskan nilai animasi menjadi keyframe permanen
Codec H.264Standar kompresi video yang didukung hampir semua pemutar
FFmpegEncoder yang di dalam Blender menjahit frame menjadi MP4
glTF / GLBFormat "JPEG-nya 3D": satu file biner berisi mesh + material + animasi untuk web

LAMPIRAN B. COOKBOOK RESEP CEPAT ​

B1. Durasi lebih panjang - ubah TOTAL_FRAMES = 480 (20 detik) lalu jalankan ulang skrip; seluruh jadwal keyframe ikut meregang.

LAMPIRAN C. BEDAH DETAIL & KODE INTI modul4_kamera_animasi_citytour.py ​

C.1 Kurva Drone + Dua Constraint ​

python
spline.bezier_points.add(7)                     # total 8 titik elips
for i in range(8):
    theta = 2.0 * math.pi * i / 8
    bp.co = (cx + rx * math.cos(theta),          # posisi elips
             cy + ry * math.sin(theta),
             z + 2.5 * math.sin(theta * 2.0))    # gelombang tinggi
spline.use_cyclic_u = True                       # tutup lingkaran
curve_data.path_duration = 240                   # 1 putaran = 240 frame
curve_data.eval_time = 0.0
curve_data.keyframe_insert("eval_time", frame=1) # animasi dari kurva,
curve_data.eval_time = 240.0                     # bukan dari kamera!
curve_data.keyframe_insert("eval_time", frame=240)

c_follow = cam1.constraints.new("FOLLOW_PATH"); c_follow.target = curve_obj
c_track = cam1.constraints.new("TRACK_TO")
c_track.target = target_focus
c_track.track_axis = "TRACK_NEGATIVE_Z"; c_track.up_axis = "UP_Y"

# Lift: jadwal eksplisit naik-turun, interpolasi BEZIER (halus)
jadwal = [(1, z_lt1), (30, z_lt1), (95, z_lt2), (145, z_lt2), (210, z_lt1), (240, z_lt1)]
for frame, z in jadwal:
    kabin.location = (x0, y0, z)
    kabin.keyframe_insert(data_path="location", frame=frame)
set_interpolasi_fcurve(kabin, mode="BEZIER")

# Mobil: dua keyframe ujung; roda berputar = jarak / radius (fisika!)
sudut_putar_total = jarak / 0.28
roda.rotation_euler = (math.radians(90), 0.0, 0.0)
roda.keyframe_insert(data_path="rotation_euler", frame=1)
roda.rotation_euler = (math.radians(90), sudut_putar_total, 0.0)
roda.keyframe_insert(data_path="rotation_euler", frame=240)
set_interpolasi_fcurve(roda, mode="LINEAR")
